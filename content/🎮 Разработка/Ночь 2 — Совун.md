# 🌙 Ночь 2 — Совун

> Цель: первая реальная угроза. Игрок может умереть.

## Статус: 🔴 Не начата

## Антагонист → [[Совун]]

## Задачи

### Поведение Совуна
- [ ] Появляется на дальних камерах, вызывает глич/шум
- [ ] Движется по камерам ближе к двери
- [ ] Реагирует на вспышку камеры — откатывается
- [ ] У двери стоит 15-20 сек → атакует если свет погас → уходит если свет есть

### Визуал
- [ ] Спрайт/анимация на камерах
- [ ] Глич-эффект на камере где он стоит

### Звук
- [ ] Искажённый крик совы
- [ ] Гул (бас) когда близко

### Death Screen
- [ ] Сцена: чёрный экран + анимация
- [ ] Кнопка "Попробовать снова" → reset ночи

### Диалоги
- [ ] Начало: Дима намекает на странности
- [ ] Середина: реакция на Совуна
- [ ] Конец (выжил): короткий финал

### Переход
- [ ] Кровать → сон → [[Ночь 3+ — Планирование]]
